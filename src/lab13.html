Lab 13: Web Applications, Databases and Monitoring at Azure

This lab is a continuation of Lab 12, where we deployed the Would You Rather app to Azure. In this lab, we will deploy the Student Feedback app to Azure.

The Student Feedback app is a simple web application that allows users to submit feedback to the instructor. The feedback is stored in a database and displayed on a web page.

The app is deployed to Azure and is accessible to the public.
